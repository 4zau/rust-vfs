# rust-vfs

Прототип VFS с регистрацией файловых систем по префиксам.
Для демонстрации можно подключить CPIO-архив:

```sh
cargo run -- sample.cpio /docs/readme.txt
cargo run -- shell sample.cpio
```

В обоих режимах архив монтируется в `/`. В интерактивном режиме команда
`ls /` показывает содержимое корня архива, а `ls /docs` перечисляет файлы в
каталоге `docs`. Относительные пути, например `cd ..`, отсчитываются от
текущего каталога. Для запуска без архива используйте `cargo run -- shell`.
